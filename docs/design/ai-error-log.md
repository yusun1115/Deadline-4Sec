# AI 보조 개발 오류 기록

새 오류는 아래 형식으로 추가한다. 과거 기록을 보완할 때 확인할 수 없는 도구·모델·프롬프트를 추정해서 채우지 않는다.

## 기록 형식

| 항목 | 기록 내용 |
| --- | --- |
| 날짜·작업 | 발생일, 관련 기능, 기준 커밋 |
| 도구·모델 | ChatGPT / Codex / Claude Code(Unity MCP) / Tripo / Suno와 확인 가능한 모델 |
| 프롬프트·입력 | 실제 입력 원문 또는 파일 링크 |
| 기대 / 실제 | 기대 동작과 관찰한 오류 |
| 재현 조건 | 시드, FPS 조건, 입력 순서, 씬, 기기·OS |
| 원인·수정 | 분석 결과, 수정 파일, 변경 이유 |
| 재검증 | 같은 조건의 결과, 자동 재현과 실기기 결과 구분 |
| 추적 | Issue, PR, 커밋, 스크린샷·로그 경로 |

## 과거 개발 사례: 튜토리얼 슬램 표적 배치

- 날짜: 2026-09-27 개발 기록 기준.
- 도구·모델·프롬프트: 당시 미기록. 특정 AI의 오류로 단정하지 않음.
- 기대: 10단계에서 슬램 착지 후 주변 표적을 처치하고 연습을 완료.
- 실제: 슬램은 발생했으나 표적이 멀어 처치하지 못하고 타이머 만료.
- 재현: 10단계 안내 입력 재생, 상세 높이·점수는 `Verification/tutorial-failure-slam.txt`.
- 수정: 판정 반경과 최소 높이를 유지하고 표적 Z를 23.5m에서 21.5m로 조정.
- 결과: 당시 30/60 FPS 조건에서 10단계 완료. 현재 리비전의 전체 회귀 결과와 구분.
- 근거: `TASKS.md`의 P1-03, `Verification/tutorial-replay.txt`, `tutorial-replay-30fps.txt`.
