# Deadline:4초 중간고사 기획서

중간 과제용 게임 기획 자료다. 설계 기준일은 2026-10-26이며 1인 개발 프로젝트의 구현 현황과 기말까지의 계획을 구분했다.

## 기획 문서

- [마크다운 기획서](game-design.md): 공지의 필수 항목에 따른 기획 문서.
- [외부·생성형 에셋 등록부](asset-register.md).
- [AI 보조 개발 오류 기록](ai-error-log.md).
- [기존 커밋 제목 변경 전후 목록](../development/commit-history.md).

일부 에셋의 라이선스 원문과 개별 생성 이력은 등록부에 후속 확인 대상으로 표시했다.

GitHub에는 마크다운 기획 문서와 관련 기록을 관리한다.

과제 공지의 중간 제출 마감은 **2026-10-29(목) 11:00 KST**다. LMS에서 요구하는 PDF는 별도로 준비해 저장소 링크와 함께 제출한다.

## 기록

2026-10-28에 기존 커밋 13개의 제목을 실제 변경 내용에 맞게 정리했다. 각 커밋의 파일 스냅샷, 작성자와 작성·커밋 날짜는 보존했다. 기존 ID가 들어 있는 당시 개발 기록은 변경 전후 목록으로 추적할 수 있다.

같은 날 발표·제출용 바이너리 파일을 문서 폴더에서 제거하고, 기획서와 관련 기록을 마크다운으로 정리했다.
